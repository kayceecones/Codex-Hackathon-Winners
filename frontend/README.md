# Reason — UX / Frontend

Frontend workspace for the Reason hackathon project.

## Scope

Person 4 owns the frontend experience:

- Shared project workspace
- Planning queue
- Live activity
- Workflow state
- Plan review / approvals
- Execution review
- Coding progress
- Results and decision history

The frontend should remain state-driven and API-friendly so it can integrate with the orchestration/backend layer without moving workflow logic into UI components.

## Initial implementation

Start with the main project workspace using local mock data. Keep the happy path simple and polished before connecting backend APIs.
